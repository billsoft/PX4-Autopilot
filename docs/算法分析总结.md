## 核心算法要点回顾

### 一、IMU数据处理链

```
原始传感器数据 (8kHz)
    ↓
[校准] 偏置/缩放/旋转矩阵补偿
    ↓
[积分] 角速度→δang, 加速度→δvel
    ↓
[圆锥补偿] 提升姿态精度10倍
    ↓
[质量监控] 振动/剪切/温度检测
    ↓
vehicle_imu消息 (250Hz) → EKF2
```

**关键技术**:
- 圆锥补偿公式: `Δθ = Σω·dt + (1/12)·(Δθₖ₋₁ × Δθₖ)`
- Welford在线方差: 单遍扫描、数值稳定
- 剪切检测: ADC饱和检测 + 幅值阈值

### 二、EKF2状态预测

**状态方程**:
```
q̇ = 0.5·q ⊗ ω                           # 四元数微分
v̇ = R(q)·(a - b_a) + g - 2Ω×v          # 速度预测
ṗ = v                                   # 位置预测
ḃ_gyro = w_g,  ḃ_accel = w_a            # 偏置随机游走
```

**协方差预测**:
```
P_{k+1|k} = F·P_k·F^T + Q
```
- `F`: 符号推导自动生成（SymPy）
- `Q`: 自适应调整（故障时增大100倍）

**创新点**:
1. **自适应噪声**: 传感器故障→增大Q→降低卡尔曼增益K→减少对故障源依赖
2. **软限幅**: 融合零创新观测而非硬截断（保持一致性）
3. **高阶动力学**: 科里奥利力、地球自转修正

### 三、多传感器融合控制

**融合优先级**:
```
倾斜对齐 (重力) → 磁力计 (航向) → GPS (位置/速度)
    ↓
光流/激光测距 (高度/速度) → 气压计 (高度)
    ↓
外部视觉/辅助传感器
    ↓
故障容错: 假位置/零速度约束
```

**质量门控**:
- 传感器级: 质量检查（GPS卫星数/精度因子/漂移）
- 创新级: 马氏距离检验（`test_ratio = innov² / (gate²·innov_var)`）
- 状态级: 一致性验证（多源交叉验证）

**自动切换**:
```cpp
if (primary_source_faulty) {
    switch_to_backup_source();
    reset_biases();
    increase_process_noise();
}
```

## 与标准EKF的关键差异

| 特性 | 学术标准EKF | PX4 EKF2 |
|-----|------------|---------|
| **姿态表示** | 欧拉角（有奇异点） | 四元数（全局无奇点） |
| **积分精度** | 一阶欧拉 | 二阶梯形+圆锥补偿 |
| **雅可比矩阵** | 手工推导（易错） | SymPy符号自动生成 |
| **噪声模型** | 固定Q矩阵 | 自适应Q（故障/场景相关） |
| **传感器融合** | 单一源或简单组合 | 多源智能切换+健康监控 |
| **故障处理** | 无或简单门限 | 三级容错（检测/隔离/重构） |
| **计算效率** | O(n³)全矩阵 | 稀疏优化+代码生成 |

## 常见问题诊断

### 1. 高度漂移
**症状**: 垂直位置缓慢偏移

**可能原因**:
- 气压计温度漂移
- 地效干扰（旋翼下洗）
- 加速度计Z轴偏置

**解决方案**:
```cpp
// 增大气压偏置过程噪声
EKF2_BARO_NOISE = 5.0  // 从2.0增大

// 启用地效补偿
EKF2_GND_EFF_DZ = 5.0

// 检查加计校准
commander calibrate accel
```

### 2. 航向抖动
**症状**: 偏航角高频震荡

**可能原因**:
- 磁干扰（电机/电流）
- 磁场创新门限过松
- GPS航向与磁航向冲突

**解决方案**:
```cpp
// 收紧磁场门限
EKF2_MAG_GATE = 2.0  // 从3.0减小

// 切换到GPS航向（双天线GPS）
EKF2_GPS_CTRL = 15  // 启用GPS_YAW

// 或禁用磁力计
EKF2_MAG_TYPE = 5  // NONE
```

### 3. 速度估计发散
**症状**: 速度估计快速增长至不合理值

**可能原因**:
- 加速度计剪切未检测
- GPS信号丢失
- 陀螺偏置未收敛

**解决方案**:
```cpp
// 检查IMU剪切标志
listener vehicle_imu_status

// 增大加计过程噪声
EKF2_ACC_NOISE = 1.0  // 从0.35增大

// 启用假位置约束
EKF2_NOAID_TOUT = 5000000  // 5秒后启用
```
