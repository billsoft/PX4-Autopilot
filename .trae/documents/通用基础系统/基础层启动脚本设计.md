# 基础层启动脚本设计

目标：仅启动平台/驱动/外部接口，不加载 EKF2/控制器/导航，获取 IMU/GNSS/RTK 原始数据并开放外部通信。

## rc.txt 示例（SD 覆盖）

```sh
# 设定 ROMFS 根（可选）
set R /

# 串口配置（自动生成的 rc.serial）
. ${R}etc/init.d/rc.serial

# 传感器驱动与聚合
. ${R}etc/init.d/rc.sensors
sensors start

# 可选：启动 GPS 驱动以获取 GNSS/RTK 原始数据
# 请将 /dev/ttySx 替换为实际 GNSS 串口；-p 指定协议（如 ubx）
# gps start -d /dev/ttySx -p ubx

# MAVLink：若 USB CDC 自动化失败，回退并在 ACM 启动
if param greater -s SYS_USB_AUTO -1
then
    if ! cdcacm_autostart start
    then
        sercon
        mavlink start -d /dev/ttyACM0
    fi
fi

# 禁止加载机型、估计器、控制、导航（不调用 rc.autostart/rc.vehicle_setup）
# 可按需设置参数以抑制模块自启（示例）
param set EKF2_EN 0
# param set ATT_EN 0
# param set LPE_EN 0

# 系统就绪通知
mavlink boot_complete
```

## 启停矩阵

- 启动：`rc.serial`、`rc.sensors`、`sensors`、`mavlink`、（可选）`gps`
- 不启动：`rc.autostart`、`rc.vehicle_setup`、`ekf2`、`local_position_estimator`、`attitude_estimator_q`、`mc_*`、`fw_*`、`navigator`

## GPS/RTK 路径说明

- 外部通过 MAVLink 发送 `GPS_RTCM_DATA` → `src/modules/mavlink/mavlink_receiver.cpp:2603-2620` 发布 `gps_inject_data` → 驱动处理注入（`src/drivers/gps/devices/src/gps_helper.h:288-297`、`src/drivers/gnss/septentrio/septentrio.cpp:352`）。

## 切换与编译步骤

- 运行时切换：
  - 切到基础模式：将本文件的 `rc.txt` 内容保存到 `/fs/microsd/etc/rc.txt` 并重启。
  - 切回完整模式：删除 `/fs/microsd/etc/rc.txt` 或其内容改为 `. ${R}etc/init.d/rc.autostart`。

- 编译 Pixhawk 6X 固件：
  - 完整固件：`make px4_fmu-v6x_default`；上传：`make px4_fmu-v6x_default upload`
  - 基础固件（两选一）：
    - A. ROMFS 内嵌基础脚本：在 `ROMFS/px4fmu_common/init.d` 添加 `rc.base_core` 并通过 `px4_add_romfs_files(...)` 打包；运行仍由 SD `rc.txt` 触发执行。
    - B. 创建新 `.px4board` 变体：复制 `boards/px4/fmu-v6x/*.px4board` 为新变体，裁剪模块并构建 `make px4_fmu-v6x_<variant>`。

## 验证指引

- `listener sensor_imu`、`listener sensor_gps` 验证原始数据；`uorb top` 查看更新率。
- `top` 或 `ps` 确认未运行 `ekf2/控制器/导航` 模块。
- `mavlink` 检查心跳、参数交互与 RTCM 注入后 `sensor_gnss_relative`。

## 注意事项

- 串口设备名与波特率由 `rc.serial` 自动生成与硬件布线决定；请在其后启动驱动与 MAVLink。
- 无 SD 或量产场景推荐内嵌 ROMFS 方案；调试迭代推荐 SD 覆盖方案。
