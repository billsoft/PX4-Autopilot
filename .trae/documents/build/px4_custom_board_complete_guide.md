# PX4 自定义飞控板完整开发指南

## 📖 文档目的

本文档修正了 `nucleo_h743zi_step_by_step.md` 的关键遗漏,提供**完整、正确**的自定义飞控板开发流程。

**本指南解决的核心问题:**
1. ❌ **错误认知**: 以为只需创建 `boards/{vendor}/{model}/` 目录即可
2. ❌ **遗漏关键配置**: 没说明必须使用 `CONFIG_ARCH_BOARD_CUSTOM`
3. ❌ **board.h 误解**: 不知道必须完全自包含,不能 `#include` NuttX 内置板子
4. ❌ **编译错误不理解**: 为什么错误出现在编译后期 (NuttX 阶段)

---

## 🎯 两种板子类型对比

### ❌ 类型A: 直接使用 NuttX 内置板子 (不推荐)

```
boards/st/nucleo-h743zi/
└─ (直接使用 NuttX 的 nucleo-h743zi)
```

**问题:**
- 无法自定义引脚
- `make distclean` 后修改丢失
- 需要修改 `platforms/nuttx/NuttX/` 子模块 (违反PX4规范)

### ✅ 类型B: 完全自定义板子 (标准做法,类似 fmu-v6x)

```
boards/{vendor}/{model}/
├─ nuttx-config/
│  ├─ include/board.h        ⭐ 完整自包含 (400+行)
│  ├─ nsh/defconfig           ⭐ CONFIG_ARCH_BOARD_CUSTOM=y
│  └─ Kconfig
├─ src/
│  ├─ board_config.h
│  ├─ spi.cpp
│  └─ init.c
└─ default.px4board
```

**优势:**
- ✅ 完全控制硬件配置
- ✅ 所有配置在 PX4 源码树内,不修改子模块
- ✅ 符合 PX4 标准做法

**本指南采用类型B!**

## 🔑 核心原则 (必读!)

### 原则1: 永远不修改 NuttX 子模块

```bash
# ❌ 错误做法
vim platforms/nuttx/NuttX/nuttx/boards/arm/stm32h7/nucleo-h743zi/include/board.h

# ✅ 正确做法
vim boards/st/nucleo-h743zi-fc/nuttx-config/include/board.h
```

**原因:** `make distclean` 会重置子模块,丢失修改!

### 原则2: 必须使用 CONFIG_ARCH_BOARD_CUSTOM

**defconfig 核心配置:**
```kconfig
# boards/{vendor}/{model}/nuttx-config/nsh/defconfig

# ⭐ 这是关键! 告诉 NuttX 使用自定义板子目录
CONFIG_ARCH_BOARD_CUSTOM=y
CONFIG_ARCH_BOARD_CUSTOM_DIR="../../../../boards/{vendor}/{model}/nuttx-config"
CONFIG_ARCH_BOARD_CUSTOM_DIR_RELPATH=y
CONFIG_ARCH_BOARD_CUSTOM_NAME="{model}"

# 不要用这个! (会指向 NuttX 内置板子)
# CONFIG_ARCH_BOARD="nucleo-h743zi"
# CONFIG_ARCH_BOARD_NUCLEO_H743ZI=y
```

### 原则3: board.h 必须完全自包含

**❌ 错误做法:**
```c
// boards/{vendor}/{model}/nuttx-config/include/board.h
#include "../../../../../../platforms/nuttx/NuttX/nuttx/boards/arm/stm32h7/nucleo-h743zi/include/board.h"

#undef GPIO_SPI1_MOSI
#define GPIO_SPI1_MOSI (GPIO_SPI1_MOSI_2 | GPIO_SPEED_50MHz)
```

**问题:**
1. 相对路径在编译时找不到
2. NuttX 内置 board.h 可能缺少你需要的定义

**✅ 正确做法:**
```c
// boards/{vendor}/{model}/nuttx-config/include/board.h
#ifndef __BOARDS_{VENDOR}_{MODEL}_NUTTX_CONFIG_INCLUDE_BOARD_H
#define __BOARDS_{VENDOR}_{MODEL}_NUTTX_CONFIG_INCLUDE_BOARD_H

#include <nuttx/config.h>

// ⭐ 完整的时钟配置 (从 NuttX 类似板子复制)
#define STM32_BOARD_XTAL        8000000ul
#define STM32_HSE_FREQUENCY     STM32_BOARD_XTAL
#define STM32_PLLCFG_PLL1N      RCC_PLL1DIVR_N1(240)  // 480MHz
// ... (400+ 行完整定义)

// ⭐ 自定义 GPIO 定义
#define GPIO_SPI1_SCK     (GPIO_SPI1_SCK_1 | GPIO_SPEED_50MHz)
#define GPIO_SPI1_MISO    (GPIO_SPI1_MISO_1 | GPIO_SPEED_50MHz)
#define GPIO_SPI1_MOSI    (GPIO_SPI1_MOSI_2 | GPIO_SPEED_50MHz)
// ...

#endif
```

**工作量:** 400-800 行 (从 NuttX 类似板子复制并修改)

### 原则4: 参考 fmu-v6x,不是 nucleo

**❌ 不要参考:**
- `platforms/nuttx/NuttX/nuttx/boards/arm/stm32h7/nucleo-h743zi/`

**✅ 应该参考:**
- `boards/px4/fmu-v6x/` - 完整的自定义板子示例
- 然后查看 `platforms/nuttx/NuttX/nuttx/boards/arm/stm32h7/nucleo-h743zi/` 获取硬件定义

### 步骤3: 创建 board.h (⭐ 最复杂!)

**文件:** `nuttx-config/include/board.h`

**方法: 从 NuttX 类似板子复制完整内容**

```bash
# 1. 找到 NuttX 中最相似的板子
cd ../../../../platforms/nuttx/NuttX/nuttx/boards/arm/stm32h7/
ls
# 输出: nucleo-h743zi, nucleo-h745zi-neo, stm32h743i-eval, ...

# 2. 复制整个 board.h 作为起点
cp nucleo-h743zi/include/board.h \
   ../../../../boards/${VENDOR}/${MODEL}/nuttx-config/include/board.h

cd ../../../../boards/${VENDOR}/${MODEL}/
```

**3. 修改 board.h**

打开 `nuttx-config/include/board.h`,修改:

**A. 修改头部守卫:**
```c
// 原来:
#ifndef __BOARDS_ARM_STM32H7_NUCLEO_H743ZI_INCLUDE_BOARD_H
#define __BOARDS_ARM_STM32H7_NUCLEO_H743ZI_INCLUDE_BOARD_H

// 改为:
#ifndef __BOARDS_{VENDOR_UPPER}_{MODEL_UPPER}_NUTTX_CONFIG_INCLUDE_BOARD_H
#define __BOARDS_{VENDOR_UPPER}_{MODEL_UPPER}_NUTTX_CONFIG_INCLUDE_BOARD_H
```

**B. 修改时钟配置 (如需要):**
```c
/* PLL1, wide 4 - 8 MHz input, enable DIVP, DIVQ, DIVR
 *
 *   PLL1_VCO = (8,000,000 / 2) * 240 = 960 MHz  // 改为 240 (原来是200)
 *
 *   PLL1P = PLL1_VCO/2  = 960 MHz / 2   = 480 MHz  // 改为 480MHz (原来400MHz)
 *   PLL1Q = PLL1_VCO/4  = 960 MHz / 4   = 240 MHz
 *   PLL1R = PLL1_VCO/8  = 960 MHz / 8   = 120 MHz
 */

#define STM32_PLLCFG_PLL1N       RCC_PLL1DIVR_N1(240)  // 改为 240
#define STM32_VCO1_FREQUENCY     ((STM32_HSE_FREQUENCY / 2) * 240)  // 改为 240
```

**C. 添加自定义 GPIO 定义:**

在 `/* Alternate function pin selections */` 部分添加/修改:

```c
/* SPI1 - ICM42688P IMU1 (PX4 Flight Controller)
 * Using PB5 for MOSI instead of PA7 to avoid Ethernet RMII_CRS_DV conflict
 */
#define GPIO_SPI1_SCK     (GPIO_SPI1_SCK_1 | GPIO_SPEED_50MHz)   /* PA5 - D13 */
#define GPIO_SPI1_MISO    (GPIO_SPI1_MISO_1 | GPIO_SPEED_50MHz)  /* PA6 - D12 */
#define GPIO_SPI1_MOSI    (GPIO_SPI1_MOSI_2 | GPIO_SPEED_50MHz)  /* PB5 - Avoids PA7 conflict */

/* SPI3 - ICM42688P IMU2
 * Using SPI3 instead of SPI2 to avoid Ethernet conflict on PB13
 */
#define GPIO_SPI3_MISO    (GPIO_SPI3_MISO_1 | GPIO_SPEED_50MHz) /* PB4 */
#define GPIO_SPI3_MOSI    (GPIO_SPI3_MOSI_4 | GPIO_SPEED_50MHz) /* PB5 - Shared */
#define GPIO_SPI3_SCK     (GPIO_SPI3_SCK_1 | GPIO_SPEED_50MHz)  /* PB3 */
#define GPIO_SPI3_NSS     (GPIO_SPI3_NSS_2 | GPIO_SPEED_50MHz)  /* PA4 */

/* DMA */
#define DMAMAP_SPI1_RX DMAMAP_DMA12_SPI1RX_0 /* DMA1 */
#define DMAMAP_SPI1_TX DMAMAP_DMA12_SPI1TX_0 /* DMA1 */
#define DMAMAP_SPI3_RX DMAMAP_DMA12_SPI3RX_0 /* DMA1 */
#define DMAMAP_SPI3_TX DMAMAP_DMA12_SPI3TX_0 /* DMA1 */
```

**关键: 不要删除任何 NuttX 原有的定义!** 只添加/修改你需要的部分。

#### 5.4 led.c

**文件:** `src/led.c`

```c
#include <px4_platform_common/px4_config.h>
#include <stm32_gpio.h>
#include "board_config.h"

void led_init(void)
{
    px4_arch_configgpio(GPIO_nLED_GREEN);
    px4_arch_configgpio(GPIO_nLED_YELLOW);
    px4_arch_configgpio(GPIO_nLED_RED);
}

void led_on(int led)
{
    if (led == 0) {
        px4_arch_gpiowrite(GPIO_nLED_GREEN, LED_ON);
    } else if (led == 1) {
        px4_arch_gpiowrite(GPIO_nLED_YELLOW, LED_ON);
    } else if (led == 2) {
        px4_arch_gpiowrite(GPIO_nLED_RED, LED_ON);
    }
}

void led_off(int led)
{
    if (led == 0) {
        px4_arch_gpiowrite(GPIO_nLED_GREEN, LED_OFF);
    } else if (led == 1) {
        px4_arch_gpiowrite(GPIO_nLED_YELLOW, LED_OFF);
    } else if (led == 2) {
        px4_arch_gpiowrite(GPIO_nLED_RED, LED_OFF);
    }
}

void led_toggle(int led)
{
    if (led == 0) {
        px4_arch_gpiowrite(GPIO_nLED_GREEN, !px4_arch_gpioread(GPIO_nLED_GREEN));
    } else if (led == 1) {
        px4_arch_gpiowrite(GPIO_nLED_YELLOW, !px4_arch_gpioread(GPIO_nLED_YELLOW));
    } else if (led == 2) {
        px4_arch_gpiowrite(GPIO_nLED_RED, !px4_arch_gpioread(GPIO_nLED_RED));
    }
}
```

## ⚠️ 常见错误与解决

### 错误1: `GPIO_SPI1_SCK undeclared`

**症状:**
```
chip/stm32_spi.c:2617:28: error: 'GPIO_SPI1_SCK' undeclared
```

**原因:** board.h 没有定义 SPI1 引脚

**解决:**
1. 检查 `defconfig` 是否有 `CONFIG_ARCH_BOARD_CUSTOM=y`
2. 检查 `board.h` 是否包含 SPI1 GPIO 定义
3. 验证 NuttX 链接: `cat build/.../nuttx_olddefconfig.log | grep board`

### 错误2: `board.h: No such file or directory`

**症状:**
```
fatal error: ../../platforms/nuttx/NuttX/.../board.h: No such file or directory
```

**原因:** board.h 试图 `#include` NuttX 内置板子,路径错误

**解决:**
- ❌ 不要 `#include` 相对路径到 NuttX 子模块
- ✅ 从 NuttX 板子**复制**完整内容到你的 board.h

### 错误3: 编译很晚才报错

**症状:** 编译进行到 70-80% 才报错

**原因:** PX4 代码编译在前,NuttX 编译在后

**解决:** 这是正常现象,NuttX 相关错误会在后期出现

### 错误4: `make distclean` 后修改丢失

**症状:** distclean 后 SPI 配置消失

**原因:** 修改了 `platforms/nuttx/NuttX/` 子模块

**解决:**
- 永远不修改子模块
- 所有配置放在 `boards/{vendor}/{model}/`

## 🎓 核心知识点

1. **CONFIG_ARCH_BOARD_CUSTOM** 是让 NuttX 使用自定义板子的关键
2. **board.h** 必须完全自包含,包含所有时钟/GPIO/外设定义
3. **defconfig** 控制 NuttX 配置,**.px4board** 控制 PX4 模块
4. **参考 fmu-v6x**, 不要依赖 NuttX 内置板子
5. **编译错误在后期** 是因为 NuttX 编译在 PX4 之后
