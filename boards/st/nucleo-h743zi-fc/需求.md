# Nucleo-H743ZI-FC 功能与实现需求

## 目标
- 两路 `SPI` 读取 `ICM45686`（`SPI1` 与 `SPI3`）。
- 一路 `I2C1` 读取 `BMM150` 磁力计。
- 两路 `GPIO EXTI` 读取 `CMOS` 帧/行同步并生成时间戳（去抖）。
- 自研融合算法输出姿态四元数，经 `uORB` 与 `MAVLink` 通过 `USART3=/dev/ttyS2` 输出给外部相机做防抖。
- 保持最小模块集合，禁用不必要外设（例如 SD、以太网冲突的 `SPI2`）。

### 频率要求
- IMU 采样：`ICM42688P` 目标采样频率 `1000 Hz`（驱动与管道复用 v6x 板配置）。
- 融合输出：姿态四元数目标频率 `120 Hz`。
- 同步与时间戳：将 `GPIO EXTI` 帧/行同步事件用于为融合四元数打时间戳，以配合相机实现防抖与滚动快门补偿。

## 硬件与时钟
- MCU：`STM32H743ZI`（LQFP144）。
- 时钟：`HSE 8MHz` → `PLL1 SYSCLK 480MHz`；`SPI123` 时钟建议 ≤ 120–150MHz；`USART3` PCLK 96MHz 足以 `115200`。参考：`.trae/documents/build/stm32_743_cubemx时钟.md`。

## 总线与引脚
- SPI1：`PA5/PA6/PD7`；片选 `PD14`（`GPIO_SPI1_CS_ICM45686`）。
- SPI3：`PC10/PC11/PB2`；片选 `PA15`（`GPIO_SPI3_CS_ICM45686`）。
- I2C1：`PB6/PB9`（外部扩展索引 1）。
- EXTI：`PE11/PE9` 或 `PE3/PE4` 用于帧/行同步。
- HRT：`TIM5` 通道 1。参考：`.trae/documents/build/开发板接口和Pin配置.md`。

## 软件模块与启动
- 传感器驱动：`drivers__imu__invensense__icm45686`、`drivers__magnetometer__bosch__bmm150`。
- 同步采集：`modules__cmos_sync` 发布 `gpio_in`（位 0=行，位 1=帧）。
- 融合算法：`modules__dual_imu_fusion` 订阅两路 IMU 与磁力计，输出 `vehicle_attitude` 四元数（目标频率 `120 Hz`）。
- MAVLink：`TELEM1` 映射 `/dev/ttyS2`；流固定输出 `ATTITUDE_QUATERNION 100Hz`、`HIGHRES_IMU 100Hz`、`ATTITUDE 50Hz`。
- 启动脚本：
  - `icm45686 start -s -b 1 -R 0`
  - `icm45686 start -s -b 3 -R 8`
  - `bmm150 start -I -b 1 -R 0`
  - `cmos_sync start`
  - `dual_imu_fusion start`
  - `sensors start`
  - `mavlink stream -u -r 120 -s ATTITUDE_QUATERNION`
  - `mavlink stream -u -r 120 -s HIGHRES_IMU`
  - `mavlink stream -u -r 50 -s ATTITUDE`

## 数据流与话题
- 原始：`sensor_accel`、`sensor_gyro`（两路）、`sensor_mag`。
- 同步事件：`gpio_in`（时间戳与位掩码）。
- 融合输出：`vehicle_attitude`（四元数）。
- 串口输出：MAVLink 心跳与姿态/IMU 流。

## 验证
- 构建：`python Tools/px4.py build st_nucleo-h743zi-fc` 与 `wsl make st_nucleo-h743zi-fc_default -j4`。

  - `listener gpio_in`、`listener vehicle_attitude`。
  - `mavlink status` 与三条流的频率。
