## 1. 系统概述

### 1.1 项目目标
基于STM32H743ZI Nucleo开发板（一代Arduino接口），开发一个**最小飞控传感器融合系统**，实现：
- 双IMU（SPI1 + SPI3）数据采集
- 磁力计（I2C1）数据采集
- 120Hz姿态融合输出（欧拉角 + 四元数）
- MAVLink协议输出融合数据
- LED状态指示（数据状态可视化）
- CMOS同步信号采集（可选）

### 1.2 设计原则
- **模块化解耦**: 基于uORB消息总线，各模块独立订阅/发布
- **无飞控功能**: 不包含commander/navigator/控制器
- **无SD卡**: 禁用logger，最小系统
- **开发友好**: NSH可用，异步初始化，日志清晰

## 2. 硬件规格

### 2.1 核心MCU
- **型号**: STM32H743ZI (LQFP144封装)
- **主频**: 480MHz (PLL1 SYSCLK)
- **闪存**: 2MB
- **RAM**: 1MB (多个域)

### 2.2 时钟配置
```
HSE: 8MHz (ST-LINK MCO)
  ↓
PLL1: SYSCLK = 480MHz
PLL2P: SPI123 = 192MHz (≤200MHz要求)
APB1: USART3 PCLK = 96MHz (支持115200波特率)
```

### 2.3 传感器接口

#### SPI1 - IMU1 (Arduino接口)
- **位置**: Nucleo Arduino CN7/CN10接口
- **信号**:
  - SCK:  PA5 (D13 Arduino)
  - MISO: PA6 (D12 Arduino)
  - MOSI: PD7 (Morpho CN12-19, AF5)
  - CS:   PD14 (D10 Arduino)
- **设备**: ICM42688P / ICM42686 / ICM45686 (兼容`-6`参数)
- **用途**: 主IMU

#### SPI3 - IMU2 (Arduino接口)
- **位置**: Nucleo Arduino/Morpho扩展
- **信号**:
  - SCK:  PC10 (Morpho CN12-1)
  - MISO: PC11 (Morpho CN12-2)
  - MOSI: PB2 (Morpho CN12-22, AF7)
  - CS:   PA15 (Arduino D9)
- **设备**: ICM42688P / ICM42686 / ICM45686
- **用途**: 副IMU（噪声估计与融合）

#### I2C1 - 磁力计 (Arduino接口)
- **位置**: Nucleo Arduino CN5 I2C接口
- **信号**:
  - SCL: PB6 (Morpho CN12-17, AF4)
  - SDA: PB9 (D14 Arduino)
- **设备**: BMM150
- **用途**: 磁场测量（航向修正）

#### EXTI - CMOS同步 (可选)
- **信号**:
  - 帧同步: PE3 (EXTI3中断)
  - 行同步: PE4 (EXTI4中断)
- **用途**: 相机帧/行同步时间戳

### 2.4 LED指示
- **LED1 (绿色)**: PB0 - 指示SPI1 IMU1状态
- **LED2 (黄色)**: PB7 - 指示SPI3 IMU2状态
- **LED3 (红色)**: PB14 - 指示I2C1磁力计状态
- **极性**: 高电平有效（1=亮，0=灭）

### 2.5 通信接口
- **USART3 (VCP)**: PD8 (TX) / PD9 (RX)
  - 波特率: 115200-8N1
  - 用途: NSH控制台 + MAVLink输出
- **USB FS** (未使用): PA8/PA9/PA11/PA12

### 3.2 核心模块定义

#### 模块1: 传感器驱动层
**名称**: `icm42688p` (SPI1/SPI3)
**职责**:
- 初始化IMU硬件（寄存器配置、自检）
- 周期性读取加速度计、陀螺仪数据
- 发布uORB消息:
  - `sensor_accel` (实例0: SPI1, 实例1: SPI3)
  - `sensor_gyro` (实例0: SPI1, 实例1: SPI3)
- **频率**: 内部采样1kHz，输出约200Hz（硬件FIFO）

**名称**: `bmm150` (I2C1)
**职责**:
- 初始化磁力计硬件
- 周期性读取磁场数据
- 发布uORB消息:
  - `sensor_mag` (实例0)
- **频率**: 约100Hz

**配置参数**:
```bash
# SPI1 IMU1
icm42688p start -s -b 1 -R 0 -6
# -s: SPI模式
# -b 1: SPI总线1
# -R 0: 旋转矩阵0度（板载方向）
# -6: 兼容42686/45686芯片

# SPI3 IMU2
icm42688p start -s -b 3 -R 8 -6
# -R 8: 旋转270度（根据实际安装）

# I2C1 Mag
bmm150 start -I -b 1 -R 0
# -I: I2C模式
# -b 1: I2C总线1
```

---

#### 模块2: 双IMU融合算法
**名称**: `dual_imu_fusion`
**位置**: `src/modules/dual_imu_fusion/`
**职责**:
1. **噪声估计**:
   ```
   噪声估计 = (IMU1数据 + IMU2数据) / 2
   ```
   - 假设两个IMU的有效信号相同，噪声随机独立
   - 相加后有效信号加倍，噪声部分相互抵消

2. **噪声去除**:
   ```
   滤波后IMU1 = IMU1数据 - 低通滤波(噪声估计)
   ```
   - 在减法前对噪声估计进行低通滤波（平滑）
   - 避免高频噪声引入

3. **姿态融合**:
   ```
   融合输入:
     - 滤波后IMU1加速度计 (重力方向)
     - 滤波后IMU1陀螺仪 (角速度)
     - BMM150磁力计 (航向修正)

   融合算法:
     - 互补滤波器 或 Mahony滤波器
     - 输出: 欧拉角 (Roll, Pitch, Yaw)
     - 输出: 四元数 (q0, q1, q2, q3)
   ```

4. **输出uORB消息**:
   - `vehicle_attitude` (120Hz)
     - timestamp: 微秒级时间戳
     - q[4]: 四元数 [w, x, y, z]
     - rollspeed, pitchspeed, yawspeed: 角速度
     - 可选: roll, pitch, yaw欧拉角

**频率**: 120Hz（根据需求固定）

**滤波参数**（可调）:
```c
// 低通滤波器截止频率
#define NOISE_LPF_CUTOFF_HZ  10.0f  // 10Hz低通

// 融合算法增益
#define FUSION_KP  2.0f  // 比例增益
#define FUSION_KI  0.1f  // 积分增益
```

#### 模块3: LED状态指示
**名称**: `board_status_leds`
**位置**: `src/modules/board_status_leds/`
**职责**:
1. **订阅uORB消息**:
   - `sensor_accel` 实例0 (IMU1)
   - `sensor_accel` 实例1 (IMU2)
   - `sensor_mag` 实例0 (磁力计)
   - `vehicle_attitude` (融合状态)

2. **数据新鲜度判断**:
   ```c
   当前时间 - 消息时间戳 < 窗口阈值 (默认500ms)
   ```

3. **LED状态逻辑**:

   **启动阶段** (前3秒):
   ```
   三色LED慢闪（2秒周期，错开相位）
   → 表示系统已启动，正在初始化
   ```

   **正常运行**:

   | LED | 条件 | 状态 | 频率 | 说明 |
   |-----|------|------|------|------|
   | 绿色 (IMU1) | 无数据 | 慢闪 | 2秒周期 | 驱动未启动或传感器无响应 |
   | | 有数据 | 快闪 | 2Hz | IMU1数据正常 |
   | | 融合激活 | 超快闪 | 3.3Hz | 融合算法运行中 |
   | 黄色 (IMU2) | 无数据 | 慢闪 | 2秒周期 | 驱动未启动或传感器无响应 |
   | | 有数据 | 快闪 | 2Hz | IMU2数据正常 |
   | | 融合激活 | 超快闪 | 3.3Hz | 融合算法运行中 |
   | 红色 (Mag) | 无数据 | 慢闪 | 2秒周期 | 驱动未启动或传感器无响应 |
   | | 有数据 | 快闪 | 2Hz | 磁力计数据正常 |

   **注意**: 融合激活时，绿色和黄色LED**同步**3.3Hz闪烁，覆盖单独的快闪模式

4. **测试模式**:
   ```bash
   board_status_leds test 10
   # 循环显示: 绿→黄→红，每色2秒，持续10秒
   ```

**更新频率**: 100ms（10Hz）

#### 模块4: MAVLink输出
**名称**: `mavlink`
**职责**:
- USART3串口通信（115200波特率）
- 只输出**融合后的姿态数据**，不输出原始IMU
- 简化流配置，固定120Hz

**配置**:
```bash
# rc.board_sensors中配置
mavlink start -d /dev/ttyS2 -b 115200 -m minimal -r 120
# -d: USART3设备
# -b: 波特率115200
# -m: minimal模式（仅心跳+姿态）
# -r: 120Hz基础频率

# 只配置一条流（简化）
mavlink stream -d /dev/ttyS2 -s ATTITUDE_QUATERNION -r 120
```

**输出消息**:
- `HEARTBEAT`: 1Hz（自动）
- `ATTITUDE_QUATERNION`: 120Hz
  - time_boot_ms: 系统启动时间
  - q1, q2, q3, q4: 四元数
  - rollspeed, pitchspeed, yawspeed: 角速度

### 3.3 启动流程

```
1. NuttX启动
   ↓
2. board_app_initialize()
   - LED GPIO初始化（初始全灭）
   - SPI CS引脚初始化（高电平去选）
   - 绿色LED闪3次（表示板级初始化成功）
   - 创建异步任务: px4_init_thread (延迟10秒)
   ↓
3. NSH立即可用 (关键!)
   - 用户可输入命令调试
   - 观察syslog日志
   ↓
4. px4_init_thread启动 (10秒后)
   - px4_platform_init() - 挂载ROMFS、启动uORB
   - px4_platform_configure()
   - 加载rc.board_sensors脚本
   ↓
5. rc.board_sensors执行
   - 启动icm42688p (SPI1)
   - 启动icm42688p (SPI3)
   - 启动bmm150 (I2C1)
   - 启动cmos_sync (可选)
   - 启动dual_imu_fusion
   - 启动sensors (预处理)
   - 启动board_status_leds
   - 配置mavlink流
   ↓
6. 系统运行
   - 传感器数据发布 → 融合算法处理 → MAVLink输出
   - LED实时指示状态
```

## 7. 开发注意事项

### 7.1 异步初始化
- `board_app_initialize()`立即返回，不阻塞NSH
- PX4初始化在独立任务中延迟10秒启动
- 使用`syslog()`输出日志，确保可见

### 7.2 I2C晚期初始化
- 早期I2C操作易触发HardFault
- 启用`CONFIG_BOARD_I2C_LATEINIT=y`
- 由驱动首次使用时初始化

### 7.3 DMA配置
- 初期禁用SPI/UART DMA，确保稳定
- 系统验证后逐步启用优化性能

### 7.4 LED极性
- 已确认为**高电平有效** (1=亮, 0=灭)
- GPIO初始化为`OUTPUT_CLEAR`（低电平，LED关闭）

### 7.5 融合算法参数
- 噪声低通滤波截止频率: 可调（默认10Hz）
- 融合器增益: 根据实际测试调整
- 输出频率: 固定120Hz，不支持动态调整
